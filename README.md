# Brennen Griffith — Portfolio

A free, static portfolio for data integration, APIs, cloud security, and applied AI. Built with HTML, CSS, and JavaScript; no build step, backend, API keys, or paid services.

## Preview

Run `python -m http.server 4173` in this folder, then open http://localhost:4173.

## Update content

- Edit `content.js` for work history, skills, and certifications.
- Edit `index.html` for the introduction, project case study, AI section, and contact details.
- Update `styles.css` for presentation. Use relative asset paths so repository subpaths work.

## Free GitHub Pages hosting

Use a **public** repository on GitHub Free. In repository Settings → Pages, select **Deploy from a branch**, branch **main**, folder **/(root)**, and save. No custom domain is needed. The included `.nojekyll` file serves the static files directly. Push changes to `main` to update the site.

The project has no paid dependencies, tracking, or AI service calls. Codex and Gemini are described as professional tools, not integrated services.
